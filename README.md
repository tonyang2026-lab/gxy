# Windows 长截图工具

独立 Electron 桌面工具：框选屏幕正文区域，手动向下滚动并连续采集，自动寻找重叠内容拼成长图，预览与校准后保存 PNG。仅本机处理，不上传图片，不需要 API 或代理。

这个功能位于 `feat/windows-long-screenshot` 分支，原来的 ASIN 工具分支保持独立。

## Windows 启动

先安装 [Node.js 24 LTS](https://nodejs.org/)，下载本分支源码 ZIP 并解压，双击 **启动长截图.bat**。首次会联网安装依赖，稍等即可。Windows 可能隐藏文件扩展名，文件显示为“启动长截图”也可以双击。

也可以在包含 package.json 的目录打开 cmd，依次执行：

```bat
npm ci
npm start
```

首次需下载 Electron 运行程序。安装后截图与拼接可以离线使用。程序没有自动更新机制，请在新版独立文件夹内启动，避免误开旧版。

## 截一张长图

1. 打开需要截取内容的软件，调整好窗口大小。
2. 在工具中选择显示器，点击“选择区域并开始”。工具会隐藏并冻结该显示器画面，拖动框选正文区域；太小的区域（小于80×80逻辑像素）需重新框选，Esc 取消。
3. 松开鼠标后自动保存第一屏，工具继续隐藏，回到目标软件向下滚动约半屏，等待画面静止。
4. 按 **Ctrl + Shift + 1** 采集下一屏。每次向下滚动后重复此操作。请保留至少约一半重叠区域，避免快速滚动或一口气翻页。
5. 按 **Ctrl + Shift + 2** 结束采集，回到工具查看预览。快捷键只在采集期间注册，结束后释放。
6. 自动匹配不可靠的屏次会标成待校准，选择“校准重叠”，左右比较相邻屏，调整当前屏顶部阴影范围并确认。也可删除错误屏次。
7. 检查接缝与内容完整性，点击“保存 PNG”，选择保存位置。预览可能缩小，导出使用原始像素。

快捷键被占用时，使用系统托盘图标的右键菜单“采集下一屏”和“结束采集并预览”；双击托盘图标也会结束采集并显示工具。此工具只读取画面，不会自动滚动、点击或更改目标软件。

## 如何截得更准

- 仅框选滚动的正文，避开固定标题栏、导航、底部栏和持续播放的动画。适用于可正常截屏的软件、网页、聊天记录、文档等，不保证所有页面均可自动对齐。
- 保持同一个显示器、同一个窗口尺寸和区域；不要在采集中更改屏幕分辨率、缩放或旋转。
- 只向下滚动，滚动后等待静止，再按采集快捷键。完全相同的屏次会忽略。
- 大面积空白、重复表格、固定栏、动态内容和重叠太少会影响匹配；匹配算法是基于像素的启发式，成功匹配也需要人工检查。受保护视频、系统安全桌面或无录屏权限的内容可能不可用。
- 当前仅做纵向拼接，不支持自动滚动、横向或跨显示器拼接。多显示器可选择其中一个，框选位置按显示器与实际截图像素换算，覆盖高 DPI 缩放。
- 为限制内存：最多40屏、单张1200万像素、原始总量8000万像素；导出最多30000像素高且总计4000万像素，超过时需删除部分屏次并分批保存。
- 原始屏次暂存在本机临时目录，正常退出时清理，不作为恢复项目长期保存。未保存退出会确认；请先保存PNG。

## 测试和打包

```bat
npm test
npm run build:win
```

Windows 安装程序输出在 dist。未配置发布者签名，Windows 可能提示未知发布者。GitHub Actions 的 **Build Windows long screenshot tool** 工作流在本开发分支推送后构建，也可手动触发；成功后在运行页面的 Artifacts 下载 `longshot-windows-installer`，解压后运行 exe。

测试覆盖可重复的图像重叠、逐像素拼接、歧义拒绝、校准、删除屏次重新匹配和 DPI 坐标换算。Linux 云环境无法代表 Windows 实机的截屏权限、托盘、快捷键或多显示器效果，需在 Windows 实测。

本次云环境验证：9项测试通过；成功生成Windows x64免安装ZIP并检查exe、app.asar与PNG依赖均已打包。Windows桌面实机效果尚未验证。测试中的采集与快捷键流程使用Electron替身，不能代替真实系统录屏验证。
