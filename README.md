# Windows 自动滚动长截图工具

框选屏幕正文区域后，自动向下滚动、等待画面稳定、采集并拼接成长图，预览与校准后保存 PNG。也可切换手动模式。图片仅在本机处理，不上传，不需要 API 或代理。

本工具位于 `feat/windows-long-screenshot` 分支，原来的 ASIN 工具分支保持独立。

## 打开工具

安装 [Node.js 24 LTS](https://nodejs.org/)，下载本分支源码 ZIP 并解压，双击 **启动长截图.bat**。首次需要联网安装依赖和 Electron，完成后可离线使用。也可在项目目录运行：

```bat
npm ci
npm start
```

程序没有自动更新机制，请将新版解压到新文件夹，避免误开旧版。

## 自动滚动使用方法

1. 打开需要截图的网页、聊天窗口或文档，调整窗口大小。
2. 保持勾选 **自动滚动并采集**，选择显示器。滚动幅度默认“中”，等待默认1.2秒；加载慢时选2秒。
3. 点击“选择区域并开始”，拖动框选一个窗口内的滚动正文，避开固定标题、侧栏和底部栏；Esc 取消框选。
4. 松开后自动保留第一屏，将鼠标移入区域并激活目标窗口，然后自动向下滚动和采集。期间请勿移动鼠标或切换窗口。
5. 连续3次滚动后画面没有变化，会自动结束（可能到底部，也可能目标不响应滚轮）。**移动鼠标，或按 Ctrl + Shift + 2，可以随时停止。** 系统托盘菜单也可结束。
6. 回到工具检查预览，必要时校准重叠或删除错误屏次，点击“保存完整 PNG”；超过单张限制时改用“分段导出”。

自动模式只发送向下鼠标滚轮，不自动点击、不输入文字。不自动提升管理员权限。目标窗口失去焦点、移动/缩放、被其他窗口遮挡，或鼠标移离采集位置，会在下一次滚轮前停止。前台应用不接受模拟滚轮、PowerShell受系统策略限制或权限不匹配时，请使用手动模式，不要关闭系统安全限制。

固定标题、重复内容或滚动太快导致无法对齐时，会停止并保留需要校准的一屏。可减小滚动幅度后重新采集。页面一直变化会停止；达到40屏、原始截图或导出尺寸限制时也会停止。超过单张尺寸上限后不删除已采集屏次；可选择分段导出，直到到达采集数量或原始总量限制时停止。结束时若鼠标仍在自动定位处，会将其移回原位置；用户已经移动鼠标时不会抢回位置。

## 手动模式

取消勾选“自动滚动并采集”，框选区域后第一屏自动保留。每次向下滚动约半屏、等待静止，再按 **Ctrl + Shift + 1** 采集下一屏；按 **Ctrl + Shift + 2** 结束并预览。快捷键被占用时，可使用托盘菜单。快捷键仅在采集期间注册，结束后释放。

## 校准与限制

- 自动匹配成功也请检查接缝。遇到待校准屏次，选择“校准重叠”，调整当前屏顶部阴影，让它覆盖上一屏已包含的内容，再确认；0像素代表直接拼接。
- 保持同一显示器和窗口尺寸。支持选择多显示器中的一个，并按实际截图尺寸换算高 DPI 坐标；不支持横向或跨屏幕拼接。
- 适用于允许录屏的普通应用；受保护视频、安全桌面或无录屏权限的内容可能不可用。
- 最多40屏，单张1200万像素，原始总量8000万像素；单张导出最多30000像素高、4000万像素，超过时使用“分段导出”保留全部已采内容。
- 原始屏次只暂存于本机临时目录，正常退出时清理，不长期保存项目。关闭前请先导出 PNG。

## 测试与打包

```bat
npm test
npm run build:win
```

Windows 安装程序在 dist。GitHub Actions 的 **Build Windows long screenshot tool** 工作流会在本分支推送后构建；成功后在运行页面的 Artifacts 下载 `longshot-windows-installer`。安装程序未配置发布者签名。

自动滚动使用随应用打包的固定 PowerShell/C# 助手，调用 Windows 光标、前台窗口和滚轮接口；不下载远程脚本，不修改执行策略或防护设置。窗口变化、鼠标移动在每次滚动前检查。

测试覆盖自动停止/取消、稳定画面检测、对齐失败与容量限制、手动采集、逐像素拼接、校准和 DPI 坐标。Windows runner 另外运行 C# 助手编译与无鼠标输入的协议测试；Linux 会明确跳过该项。当前云环境无法代替 Windows 实机的滚轮效果、权限、托盘和多显示器验证。

## 预览与导出尺寸

预览是为界面缩小的缩略图，完整 PNG 直接使用原始拼接像素，保存前核对实际 PNG 头中的尺寸。界面分别显示原图和预览尺寸。图片查看器的“适应窗口”会把大图缩小显示，不等于文件被裁切；请查看文件像素尺寸或切换100%查看。

重叠匹配增加密集RGB与边缘校验，避免仅少量采样列相似就裁掉未重复的内容；校验不通过时需要手动校准。仍不能保证所有重复内容都能自动判断准确，请检查接缝。

“分段导出”选择一个目录，程序在其中创建独立子目录，将完整拼接内容按顺序分成多张原始像素PNG，并生成分段清单。各段不重复也不跳过像素行。“导出原始屏次”则保存全部已保留的选区截图，不去重叠、不缩放，即使尚未校准也可导出供核对。两种目录导出均不会覆盖已有文件。

达到数量/原始总量限制、目标不响应滚轮、画面不稳定等情况仍会停止采集；分段导出只保证已采集的内容，不会恢复尚未采到的页面。旧版已被裁掉或从未采集的内容需要重新截图。
