# 小星 · 本地陪伴桌宠

蜡笔风小女孩和独角兽双角色桌宠，运行时无需 API、密钥、代理或网络。

功能：透明背景置顶窗口、拖动标题栏移动、点击摸摸、喂食、玩耍、休息恢复精神、1～180 分钟休息提醒。饱食与精神保存在本地，关闭期间不衰减。提醒仅在程序运行时生效，不弹系统通知；隐藏时可用快捷键呼出查看，关闭后不保留倒计时。

这是普通桌宠，互动台词为本地预设，不提供 AI 问答、读屏或自动操作电脑。

形象使用透明背景图片 `src/assets/companions.png`，两个角色作为整体浮动、摇摆，保留原有本地互动。

## Windows 启动

安装 Node.js 24 LTS，将源码解压后，在包含 package.json 的目录打开 cmd：

```bat
npm ci
npm start
```

首次安装仍需要联网下载开发依赖与 Electron，完成后桌宠功能可离线运行。
点击减号隐藏，Ctrl + Shift + Space 呼出，点击 × 退出。
点击宠物摸摸；休息时禁用喂食、玩耍，点击“叫醒”恢复互动。
每分钟饱食减少 1；清醒时精神减少 1，休息时增加 5。
旧 AI 版本保存的密钥不会被读取或使用；不再需要的密钥可自行到服务商平台撤销。

## 测试和打包

```bat
npm test
npm run build:win
```

安装程序输出到 dist。Windows 打包工作流可在 GitHub Actions 手动触发，选择当前开发分支。未配置发布者签名。当前云环境无法实测 Windows 窗口与快捷键。

## 工作流程与随机投喂

输入任务名称，点击“添加任务”。用 ↑↓ 排序，完成后勾选，从 35 种食物中等概率随机投喂，包括水果、甜点、面包和主食（例如草莓、芒果、布丁、华夫饼、饺子和披萨），并增加对应饱食值（上限 100）。每项任务只奖励一次，取消完成再勾选不会重复奖励。已喂食物显示在任务下方，任务和奖励记录在本机保存。睡眠中也能获得任务奖励，饱食满时仍显示获得的食物。

工作任务没有计时或用时设置。原有独立“休息提醒”可自行选择是否使用。旧版任务会保留标题、顺序、完成状态，旧计时被忽略；旧版已完成任务不会补发奖励。
