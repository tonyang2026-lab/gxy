[下载不含 BAT/EXE 的源码包](downloads/amazon-template-manager-source.zip?raw=true) · [源码启动与安全说明](源码版启动说明.md)

下载后全部解压，安装 Python 3.9+，在目录中运行 `py -3 start_lan.py`（Windows）。源码包不含 BAT。首次启动设置管理员，并将窗口显示的公司内网地址发给同事。详细步骤见 [公司局域网使用指南](公司局域网使用指南.md)。


多人登录同一网站，共享原始 Excel 模板。支持站点/类目/版本检索、上传新版本、保留旧版、下载原件、完整备份及恢复。纯 Python 3.9+，无需第三方依赖。

## 新功能：库存表识别与缺少模板检查

1. 先把已有亚马逊原始模板上传入库，准确登记站点、类目、版本。
2. 打开“库存表识别”，上传 `.xlsx`、`.xlsm` 或 `.csv` 库存表，选择要上架的目标站点。
3. 点击“读取表头”，核对工作表、表头行号，以及 SKU、品名、类目列。别名可自动识别，特殊列名可以手动选。
4. 点击“分析需要的模板”，查看已有模板、需要补充、类目待确认三类结果。结果按类目汇总，保留每件商品的原表行号和判断依据。
5. 库存表有明确类目时，按同站点和同登记类目匹配；仅有品名时，内置常见品类关键词提供建议，不自动判定为确定类目。你可逐行或按同建议类目的一组商品确认/修正，然后重新检查。
6. 下载已有模板，或根据补充清单到亚马逊下载缺失的原始类目模板。导出 CSV 可查看全部商品及判断依据；页面仅显示前 200 行明细，分析最多支持 10000 行商品。

只检查缺少哪些亚马逊类目模板，不检查价格等商品资料是否齐全，也不自动填表。默认使用免费本地规则；可在管理员配置后开启付费 AI 图文识别，只有明确勾选同意后才向所选服务商发送本批商品信息。库存原件不会存入共享模板库，分析结果仅保留在当前浏览器会话；需要留档请导出报告。

## AI 图文识别与本地组合识别

详见 [AI 图文识别使用指南](AI图文识别使用指南.md)。默认推荐通义千问，支持 OpenAI 和 DeepSeek 文字适配器。支持读取标准 Excel Drawing 及可解析 WPS DISPIMG 内嵌图片；不开启 AI 图片分析时，本地规则不读取图片。

本地改进包括中英文类目别名、近似名称候选、独立参数列上下文，以及组合属性推断。例如“三件套 TSA-Compatible Lock 宽拉杆 ABS+PC 20/24/28”可以提出“行李箱”候选，并检索登记为 Luggage/拉杆箱等别名的模板，不能将单独的 TSA 锁判断成行李箱。别名、近似和模型结果仍需确认。

类目名称匹配基于库内登记，不代表亚马逊官方适用性审核；无同名类目也可能只是命名不同。内置品名关键词仅覆盖部分常见品类，不能识别的商品明确标为待确认。先核对库存列和亚马逊实际类目，再决定下载哪个模板。最近入库的版本作为候选，不代表官方最新版本。

更新现有安装：先停止软件并备份整个 `.data`，将新版源码覆盖到原软件目录，保留 `.data` 不动，再用原来的启动方式重启。不要用新建的空数据目录替换旧库。源码包不包含任何公司库存或模板原件。

## 本机启动

```sh
python app.py --create-user admin --role admin
python app.py
```

第一条命令交互输入密码（至少 12 字符，不回显）。在浏览器访问 `http://127.0.0.1:8765`，登录后可创建团队成员。

Windows 若 `python` 指向应用商店别名，请使用 `py -3` 代替 `python`；局域网一体启动入口为 `py -3 start_lan.py`。

## 店铺分类与模板内部来源识别

管理员可在“店铺对照表”粘贴三列表格：`店铺 / 卖家记号阿联酋 / 卖家记号沙特`。支持 Excel 复制的制表符文本、CSV 和 Markdown 表格，支持去除单元格中的 `<br>`。同店铺 AE/SA 记号可以不同。为了批量生成，完整卖家记号保存在服务器私有数据库及完整备份中，不写入公开软件包；请保护数据目录和备份。导入后，即使该店铺尚未存模板，也会出现在店铺选项中。冲突时整批不保存，不覆盖既有归属。

真实对照表需要在你自己部署的软件中导入，公共下载包不包含实际店铺名称或卖家记号。完整备份包含导入的目录和来源绑定，即使目录尚未关联模板也可恢复。

上传与库存分析均选择店铺。同站点、同类目、同版本可在不同店铺分别保存，不相互覆盖。匹配仅限目标店铺及允许共享的“通用模板”，本店专用模板优先；不借用其他店铺专用模板。

新版读取 Amazon `Template!A1` 设置中的 `contributorId`，识别时使用其摘要和尾号提示。第一次需要你绑定到真实店铺名称或导入对照表；以后同一标识的模板即使改名，也能提示已绑定店铺，错店保存会被拒绝。缺少可用标识时仍需手动确认，不用文件名、品牌名或 AI 猜账户归属。这是文件来源线索，不是登录认证或卖家账户所有权验证。

“设置店铺”及导入对照表只更改目录归属，不会修改原始工作簿。需要修改记号时，使用独立的“同地区多店铺模板生成”功能，生成副本并保留修改记录；不能把本地检查通过当成亚马逊处理成功。

## 上传一次，生成同地区多店铺模板

1. 升级后让管理员重新导入一次店铺对照表。旧版本只有摘要，无法从摘要还原完整记号；缺少完整记号的店铺会显示需重新导入。
2. 在“同地区 · 多店铺模板生成”选择一份 `.xlsm` 或 `.xlsx`。软件从内部主站点识别地区，AE 只列 AE 记录，SA 只列 SA 记录，不依据店铺名称后缀判断，也不提供跨地区改造。
3. 默认勾选同地区全部店铺（含已登记的来源店铺，来源相同则保留原件内容）；可调整目标名单、类目和批量版本。默认勾选“保存到共享模板库”，无需逐个店铺再次上传。
4. 点击生成。每店输出独立工作簿，并提供 ZIP 和逐店修改/入库报告。相同店铺/站点/类目/版本已有不同内容时，预检查拒绝本批入库，须使用新版本；相同文件可复用。

生成仅替换 `Template!A1` 的主 `contributorId`，保留其他元数据（包括来源偏好设置）、字段、站点、预填商品、样式、验证、图片和 VBA 内容。不修改源文件，不重建工作簿；读取生成文件确认目标标识，并检查计划外 ZIP 部件未变化。文档数字签名文件不处理。

一次最多 50 店，生成的工作簿合计最多 100 MB。个别入库因磁盘等运行故障失败时，ZIP 仍包含对应副本，报告显示失败，不会把它当成已入库。源表有商品数据时也会复制到各店，使用前请核对。

该功能基于用户已实测成功的主标识替换方式提供，不保证所有模板和店铺均能通过亚马逊审核；请以各店铺处理报告为准。批量生成不调用 AI、不收取模型调用费用，也不会自动向亚马逊提交。

含来源账户标识的模板不能标为通用模板。旧数据升级时保留原件，旧店铺未知的账户模板显示“需绑定店铺”，绑定前不参与通用匹配。通过“设置店铺”更正同一来源归属时，会原子地调整同账户来源的全部已存模板，冲突时全部保持不变。普通无账户来源模板只调整选中项。

会显示模板内部主站点、商品类型、字段数量、数据起始行和预填内容提醒，不会清空或重建原件。相同商品类型不代表不同店铺模板可以互换，也不能用固定列号填不同文件。

店铺分类不改变账号权限：当前团队成员仍可查看所有店铺，分类用于组织与避免误选，不是店铺之间的访问隔离。

## 多人共享部署

所有人必须连接同一台长期在线的电脑或服务器。各自运行一份软件会创建独立模板库，不会自动共享。

局域网示例，假设运行电脑的内网地址为 `192.168.1.10`：

```sh
python app.py --host 0.0.0.0 --allowed-host 192.168.1.10:8765
```

在可信局域网访问该地址，并在操作系统防火墙仅放行可信网段。HTTP 不加密；互联网部署须使用 HTTPS 反向代理，后端只绑定回环地址：

```sh
python app.py --host 127.0.0.1 --allowed-host templates.example.com --https --data-dir /srv/template-manager/data/library
```

例如 Caddy 配置（域名解析到服务器，安装 Caddy 并开放 80/443）：

```caddyfile
templates.example.com {
    reverse_proxy 127.0.0.1:8765 {
        header_up Host {host}
    }
}
```

将软件作为受系统进程管理器监管的单个实例运行；不要在不同进程、不同磁盘同时运行多个写入实例。当前采用单进程串行写入，适用于小团队文件共享。

## 权限与数据

- 管理员：admin，可上传、下载、备份、恢复到空库、添加成员。
- 编辑者：editor，可上传新版本、查看、下载、备份。
- 只读：viewer，可查看、下载、备份。团队成员均可读取全部模板，不存在私有文件夹。

默认数据在 `.data/library/`，账号和会话在 `.data/accounts.sqlite3`。可用 `--data-dir` 指向持久磁盘，账号文件位于该目录的上一级。保留同一数据目录即可跨重启复用。

“完整备份”包含原件、模板索引及店铺归属，恢复时从原件重建来源绑定，不含登录账号密码和 AI 密钥；恢复仅允许空模板库，账号保持独立。备份上传最大 32 MB，展开最大 512 MB；超过此规模时停服复制整个 `.data` 目录。迁移账号需停服备份整个数据父目录，并安全保存。不要将 `.data` 提交到公共仓库。

上传只验证 OOXML 基本结构并校验文件哈希，不会执行宏，也不能保证是亚马逊官方有效模板。所有原件以原始字节保存；同站点/类目/版本不允许不同内容覆盖。

这是模板文件共享工具，不是多人同时编辑 Excel 单元格的软件，也不会自动填写商品数据。文件可下载后交给现有 Amazon 填表技能处理。

当前账号管理支持新增；停用/改密尚无图形界面。管理员如需紧急撤销成员访问，可停服后通过受控 SQLite 管理操作移除该账号和会话；此版本适合受信任小团队试用，不宜作为大规模公共网盘。
