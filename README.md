# 小星 · 本地陪伴桌宠

蜡笔风小女孩和独角兽双角色桌宠，陪伴、任务和排程功能无需 API、密钥或网络；可选的竞品采集需要能访问 Amazon 的网络。

功能：透明背景置顶窗口、拖动标题栏移动、点击摸摸、喂食、玩耍、休息恢复精神、1～180 分钟休息提醒。饱食与精神保存在本地，关闭期间不衰减。提醒仅在程序运行时生效，不弹系统通知；隐藏时可用快捷键呼出查看，关闭后不保留倒计时。

这是普通桌宠，互动台词为本地预设，不提供 AI 问答、读屏或自动操作电脑。

形象使用透明背景图片 `src/assets/companions.png`，两个角色作为整体浮动、摇摆，保留原有本地互动。

## Windows 启动

安装 Node.js 24 LTS，将源码解压后，在包含 package.json 的目录打开 cmd：

```bat
npm ci
npm start
```

首次安装仍需要联网下载开发依赖与 Electron，完成后桌宠功能可离线运行。
点击减号隐藏，Ctrl + Shift + Space 呼出，点击 × 退出。
点击宠物摸摸；休息时禁用喂食、玩耍，点击“叫醒”恢复互动。
每分钟饱食减少 1；清醒时精神减少 1，休息时增加 5。
旧 AI 版本保存的密钥不会被读取或使用；不再需要的密钥可自行到服务商平台撤销。

## 工作流程与随机投喂

输入任务名称，点击“添加任务”。用 ↑↓ 排序，完成后勾选，从 35 种食物中等概率随机投喂，包括水果、甜点、面包和主食（例如草莓、芒果、布丁、华夫饼、饺子和披萨），并增加对应饱食值（上限 100）。每项任务只奖励一次，取消完成再勾选不会重复奖励。已喂食物显示在任务下方，任务和奖励记录在本机保存。睡眠中也能获得任务奖励，饱食满时仍显示获得的食物。

工作任务没有计时或用时设置。原有独立“休息提醒”可自行选择是否使用。旧版任务会保留标题、顺序、完成状态，旧计时被忽略；旧版已完成任务不会补发奖励。

## 亚马逊全流程模板

工作流程面板提供每日巡检、商品上架与优化、广告复盘、库存补货、售后与买家服务、每周复盘共 6 套模板，43 项通用检查步骤。选择后可先预览，再添加到任务清单；跳过同名未完成任务，不覆盖已有进度，达到 100 项上限时显示未添加数量。已完成的工作可在下次添加模板时生成新任务，并重新获得一次食物奖励。

模板是离线工作清单，不接入卖家账号，不执行平台操作，不包含问答或自动更新的政策知识；不同站点、类目、履约方式的要求须以卖家平台当前说明为准。

## 本地自动排程（不启动倒计时）

在任务下填写预计用时（1～480分钟）、优先级和可选的当天截止时间；展开“自动安排日程”，设置日期、上/下班和午休，点击“安排日程”。先按当天截止时间、再按优先级分配，同条件保留任务顺序。默认上午09:30～12:00、下午14:00～18:00，午休12:00～14:00，可修改并保存。若已有旧作息，点击“使用我的作息”即可恢复此设置，再点击“安排日程”。任务默认30分钟，需要按实际情况调整。

今天从当前时间起排程，未来日期从上班时间起；不排过去日期或跨夜班次。长任务允许跨午休分段，不与午休重叠。排不下的任务单独提示，不自动加班或延到次日；超出截止时间时提示调整。完成项不排入。任务及设置变化后需重新点击生成，不自动执行或开始计时。排程采用电脑本地时区；截止时间是所选日期的本地时间，不转换亚马逊站点时区。

## ASIN 竞品采集与规则评分

展开“ASIN 竞品采集与规则评分”，填写 ASIN（或商品链接）、站点和核心搜索词，点击开始。支持美国、英国、德国、法国、日本、阿联酋（amazon.ae）、沙特（amazon.sa）站；页面结构不同可能需要适配。只填 ASIN 时先读取目标标题并提供简单英文提词建议，须人工核对、补充后再次开始，不自动假设语义词库。每行一个关键词，最多 5 个。

采集范围：目标详情页、详情页提供的 BSR 链接前 2 页、每个搜索词的前 1～5 页，以及最多 150 个候选详情页。默认每词 1 页、读取 30 个候选详情。频次高的候选优先读取详情；其余仍导出，但分类标记为信息不足。顺序请求、间隔至少 5 秒，每次请求超时 30 秒。使用独立的非持久 Electron 会话及系统代理，不登录卖家账户。

进度显示当前阶段；取消后等待当前请求结束。验证码、403、429、空页面解析失败会停止并保留部分结果，不绕过验证。点击“加载历史”选择任务，可手动继续未完成部分；继续前应解决网络或访问问题。未找到 BSR 链接会明确提示缺失，不以搜索页代替完整榜单覆盖。历史任务及原始 HTML 页面保存在应用用户数据目录 competitors 下，供核对与断点恢复，不会自动上传。历史选择器显示最近30项。

规则评分固定为 rules-v1：标题词集合相似度占 50%、完整核心词覆盖占 40%、来源命中次数（5次封顶）占10%，输出0～10分。来源命中按“来源类型+关键词+页”去重，不把同一页面重复卡片算成多次。最好位次表示具体页和卡片序号，包含页面展示卡片，不声称是自然排名。品牌、价格、配件词用于分类提示；价格缺失或币种不确定时不比较，不把页面价格随意除以100。

分类包含直接竞品规则候选、同品牌家族、配件耗材提示、同类不同款提示、低相关和待复核。未成功读取详情的候选单独标记信息不足；本版本不自动推断“替代方案”。规则不是 Jev、不是模型概率，也不代表竞争威胁或真实流量重合，需人工复核。

“导出Excel”可保存3个工作表：概览 / 全量候选 / 直接竞品（规则候选）。概览保留运行状态、缺失步骤和覆盖范围；部分失败也可导出现有结果。

验证范围：固定 HTML 样本覆盖解析、价格、去重，模拟请求验证采集/拒绝访问/续跑，实际 Excel 文件写入与回读验证导出。当前云环境访问 Amazon 被网关以403拒绝，未验证真实页面和 Windows Electron 实际连通性；不保证 Amazon 页面长期兼容。

中东站点识别 AED / SAR 及常见阿拉伯币种文字，支持阿拉伯数字与千位、十进制分隔符。英文和阿拉伯文核心词均可手动输入；自动提词仅支持简单英文标题。中东页面未完成实时采集验证。
