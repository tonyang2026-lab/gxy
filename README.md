# 模板仓 · 亚马逊团队模板管理

## 下载公司局域网版

[点击下载 ZIP 软件包](downloads/amazon-template-manager-lan.zip?raw=true)

下载后全部解压，先安装 Python 3.9+，再双击 `启动局域网共享.bat`。首次启动设置管理员，并将窗口显示的公司内网地址发给同事。详细步骤见 [公司局域网使用指南](公司局域网使用指南.md)。


多人登录同一网站，共享原始 Excel 模板。支持站点/类目/版本检索、上传新版本、保留旧版、下载原件、完整备份及恢复。纯 Python 3.9+，无需第三方依赖。

## 本机启动

```sh
python app.py --create-user admin --role admin
python app.py
```

第一条命令交互输入密码（至少 12 字符，不回显）。在浏览器访问 `http://127.0.0.1:8765`，登录后可创建团队成员。

Windows 安装 Python 时选中 Add Python to PATH，然后在解压目录打开终端执行以上命令。也可双击 `start-windows.bat`（需先创建管理员）。

## 多人共享部署

所有人必须连接同一台长期在线的电脑或服务器。各自运行一份软件会创建独立模板库，不会自动共享。

局域网示例，假设运行电脑的内网地址为 `192.168.1.10`：

```sh
python app.py --host 0.0.0.0 --allowed-host 192.168.1.10:8765
```

在可信局域网访问该地址，并在操作系统防火墙仅放行可信网段。HTTP 不加密；互联网部署须使用 HTTPS 反向代理，后端只绑定回环地址：

```sh
python app.py --host 127.0.0.1 --allowed-host templates.example.com --https --data-dir /srv/template-manager/data/library
```

例如 Caddy 配置（域名解析到服务器，安装 Caddy 并开放 80/443）：

```caddyfile
templates.example.com {
    reverse_proxy 127.0.0.1:8765 {
        header_up Host {host}
    }
}
```

将软件作为受系统进程管理器监管的单个实例运行；不要在不同进程、不同磁盘同时运行多个写入实例。当前采用单进程串行写入，适用于小团队文件共享。

## 权限与数据

- 管理员：admin，可上传、下载、备份、恢复到空库、添加成员。
- 编辑者：editor，可上传新版本、查看、下载、备份。
- 只读：viewer，可查看、下载、备份。团队成员均可读取全部模板，不存在私有文件夹。

默认数据在 `.data/library/`，账号和会话在 `.data/accounts.sqlite3`。可用 `--data-dir` 指向持久磁盘，账号文件位于该目录的上一级。保留同一数据目录即可跨重启复用。

“完整备份”包含原件和模板索引，不含账号密码；恢复仅允许空模板库，账号保持独立。备份上传最大 32 MB，展开最大 512 MB；超过此规模时停服复制整个 `.data` 目录。迁移账号需停服备份整个数据父目录，并安全保存。不要将 `.data` 提交到公共仓库。

上传只验证 OOXML 基本结构并校验文件哈希，不会执行宏，也不能保证是亚马逊官方有效模板。所有原件以原始字节保存；同站点/类目/版本不允许不同内容覆盖。

这是模板文件共享工具，不是多人同时编辑 Excel 单元格的软件，也不会自动填写商品数据。文件可下载后交给现有 Amazon 填表技能处理。

当前账号管理支持新增；停用/改密尚无图形界面。管理员如需紧急撤销成员访问，可停服后通过受控 SQLite 管理操作移除该账号和会话；此版本适合受信任小团队试用，不宜作为大规模公共网盘。
