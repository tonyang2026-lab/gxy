# 原本 · 亚马逊模板库

独立本机网页工具。解决“每次填表前都要重新下载亚马逊原始模板”：首次上传后把原件长期保存，按站点、类目、版本管理，之后直接选择复用。无需API密钥、账号登录或第三方Python包。

## Windows 打开

1. 安装 Python 3.10 或更高版本：https://www.python.org/downloads/windows/ 。安装时勾选 **Add python.exe to PATH**。已安装可跳过。
2. 解压工具文件夹，双击 **启动模板库.bat**。若从整个仓库下载，双击根目录 **启动亚马逊模板库.bat**。
3. 浏览器会自动打开。黑色窗口保持运行，最小化即可；关闭窗口即停止服务。
4. 点击“保存新模板”，选择自己从亚马逊下载的原始 `.xlsx` / `.xlsm`，填写站点、类目和版本。
5. 下次直接启动本工具选模板，不再需要重复下载。亚马逊发布新版时上传新版本，旧版仍保留。

默认本机地址是 http://127.0.0.1:8765/ ，启动地址携带访问口令，请勿分享。只监听本机，不是公网网站。Linux/macOS进入目录运行 `python3 app.py`。

## 文件长期保存在哪里

- Windows默认：`%LOCALAPPDATA%\YuanbenAmazonTemplates`（在资源管理器地址栏粘贴即可）。更新程序文件夹不会改变这个位置。
- Linux/macOS默认：程序旁的 `data/`。
- 页面“备份与恢复”显示实际目录。可用环境变量 `AMAZON_LIBRARY_DATA` 指定其他本地目录。
- `files/` 保存原始文件，`library.sqlite3` 保存分类/版本/默认设置，`outputs/` 保存生成草稿。原件SHA-256校验，下载原件字节不变。程序不自动删除模板；“归档”仅隐藏，可恢复。
- 可导出 ZIP 备份并在另一台电脑恢复。恢复重复内容时跳过，不覆盖现有默认模板。网页恢复上限24MB；更大的库请退出程序后复制整个存储目录。
- 存在电脑上不代表自动云备份；删除此存储目录或硬盘损坏会丢失资料，请定期备份。

## 填表工作台

1. 选择已保存模板，根据前12行预览确认目标工作表、唯一技术字段行和数据起始行，保存此区域设置供下次复用。
2. 上传本次商品资料，确认其工作表、字段行和起始行，点击“读取字段”。
3. 同名字段及少量明确别名会预选；逐项确认对应来源列，勾选需要检查的必填字段。
4. 生成Excel草稿和问题清单。会回读验证每个写入值，保留母版和输出扩展名。

**第一版的填表能力是显式列映射，不是完整的亚马逊智能填表引擎。** 不做自动事实推断、文案生成、变体分组，不保证满足亚马逊各类目、站点的全部必填/条件必填/下拉选项和合规规则。填表结果始终标记为草稿，不宣称已通过亚马逊上传校验。即使问题清单是0项，也必须人工审核后再上传。缺失数据不编造，公式来源不采用缓存值冒充事实，重复SKU提示人工确认。不会自动更新下载亚马逊模板。

导出从原始ZIP工作簿复制，只修改目标工作表的数据区域和dimension；原来的隐藏工作表、宏二进制、其他ZIP部件、数据验证等保留，源公式不执行。目标数据区只允许空白，含样例、旧数据或公式时停止，防止旧商品混入。日期格式、数值显示格式、外部链接、表格/验证范围延展及数字签名有效性不保证，复杂模板请先用小批量核对；单次最多3000条商品、24MB文件。源SKU请存为文本，避免Excel在导入前已经丢失前导零或长数字精度。公式文本作为inline string写入，不生成可执行公式。原件可能含宏，本工具不执行宏，请自行确认模板来源。

`examples/` 有两份纯演示工作簿：`DEMO_template_not_official.xlsx` 与 `DEMO_products.xlsx`。前者不是亚马逊官方模板，字段行3、数据行4；商品资料字段行1、数据行2，可体验完整流程。演示文件不会自动写入模板库。

## 测试

运行 `python -m unittest discover -s tests -v`。覆盖：版本和持久保存、原件字节不变、备份恢复/重复导入、校验失败、访问口令、OOXML命名空间/宏/隐藏工作表保留、公式跳过、缺失必填项、重复SKU及旧数据拒绝。

浏览器流程另用 Chromium + Playwright 验证上传、默认版本切换、字段映射、生成下载、独立openpyxl回读、备份恢复、搜索、归档/恢复和移动布局。测试数据是构造的演示表，尚未使用用户的真实亚马逊模板做兼容性验证。开发时浏览器及openpyxl只是验证工具，运行软件不需要安装它们。

本机令牌每次启动更新，浏览器sessionStorage保留当前令牌；程序重启后请使用新启动地址。如果端口已占用，关闭旧程序，或设置 `AMAZON_LIBRARY_PORT` 后运行。支持Python 3.10+；本地Linux自动化已验证，Windows启动脚本需在Windows实际环境验证。
