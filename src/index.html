WINDOWS · 本地截图

把多屏内容，接成一张长图。

框选正文区域，向下滚动，再逐屏采集。自动匹配重叠，保存为 PNG。

采集时工具窗口会隐藏
  1. 框选滚动正文，避开固定标题栏和底部栏。
  2. 在目标软件中向下滚动约半屏，等画面静止。
  3. 按 Ctrl + Shift + 1 采集下一屏。
  4. 按 Ctrl + Shift + 2 结束并预览。
快捷键被占用时，可在系统托盘的长截图图标上右键，选择“采集下一屏”或“结束采集”。Esc 取消框选。不支持自动滚动、跨屏幕拼接或受保护的视频画面。
